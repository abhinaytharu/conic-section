# Conic Sections Visualizer

## Overview
The **Conic Sections Visualizer** is an interactive educational tool designed to help users explore and understand the anatomy and properties of conic sections: parabolas, ellipses, and hyperbolas. This project combines a visually appealing web interface with mathematical computations and plots to provide an engaging learning experience.

## Features
- **Interactive Web Interface**:
  - A modern, responsive design with a dark theme and gradient-styled headings.
  - Provides an engaging user experience for exploring conic sections.

- **Mathematical Visualization**:
  - Python scripts generate detailed plots of conic sections using NumPy and Matplotlib.
  - Visualizes key components of each conic section:
    - **Parabola**: Vertex, focus, directrix, and general equation.
    - **Ellipse**: Major and minor axes, and general equation.
    - **Hyperbola**: Transverse and conjugate axes, with labeled components.

- **Educational Focus**:
  - Annotations and labels explain the mathematical properties and equations of conic sections.
  - Ideal for students and educators.

## Project Structure
- `index.html`: The main web interface with a modern design.
- `math.py`: Python script for generating plots of conic sections.

## Requirements
To run the Python script, ensure you have the following installed:
- Python 3.7+
- NumPy
- Matplotlib

## Usage
1. Clone the repository:
   ```bash
   git clone <repository-url>
   ```
2. Open `index.html` in a web browser to view the interface.
3. Run the Python script to generate conic section plots:
   ```bash
   python math.py
   ```
